# Yes on 4A — official logo masters

Supplied by the campaign 2026-09-09 (folder: "4A Web — All graphics
for different web purposes"). These are the **masters**. Nothing in
`assets/` is hand-made from them — everything is generated:

```sh
python3 tools/render_brand_assets.py
```

## The four lockups

| File | Lockup | Ink | Sits on |
|---|---|---|---|
| `horizontal-tagline-light.*` | cap + wordmark + tagline, side by side | charcoal `#323F49` + green | light grounds |
| `horizontal-tagline-dark.*` | same | green + white | dark grounds |
| `stacked-light.*` | cap above wordmark | charcoal + green | light grounds |
| `stacked-dark.*` | same | green + white | dark grounds |

`.ai` is the vector source; `.png` is the campaign's own transparent
export at the largest size they supplied (540px wide). **The PNGs cap
out at 540px** — anything bigger than that (print, a large display
graphic) has to come off the `.ai`, which needs Illustrator. There is
no SVG in the drop; ask the designer for one if the web ever needs
arbitrary scaling.

## What gets generated into `assets/`

| Output | From | Notes |
|---|---|---|
| `yes-on-4a-logo.png` | horizontal light | header, light mode. Trimmed to the alpha box so CSS `height` controls real ink, not padding |
| `yes-on-4a-logo-dark.png` | horizontal dark | header, dark mode |
| `favicon-32.png` / `-dark.png` | stacked, mark only | solid ground, not transparent — a transparent favicon vanishes into a themed tab strip |
| `apple-touch-icon.png` | stacked light, mark only | 180×180; iOS rounds the corners itself |
| `icon-192.png`, `icon-512.png` | stacked light, mark only | PWA, `purpose: any` |
| `icon-512-maskable.png` | stacked light, mark only | `purpose: maskable`; mark inset to 60% so a circular launcher crop doesn't clip the star |
| `og-image.png` | horizontal light | via `branding/og-image-master.html` + `tools/render_og_image.py` |

**Icons use the mark alone** (graduation cap + figure + star), not the
full lockup: "YES ON 4A" is unreadable below about 96px and the
tagline below about 200px. The generator finds the mark by scanning
the stacked lockup for the blank row band between the cap and the
wordmark, so a redrawn logo still crops correctly without new
hardcoded coordinates.

## Where the lockup may NOT go

Not on share cards generated by `drawCard()` in `js/app.js`. Those
keep the green **star motif**, because a volunteer's personal story
must not read as a committee production — see the 2026-09-09
amendment to Decision 058. Same family, no letterhead.

## Replacing the logo

Drop the new files in with these same eight names, run the generator,
and re-run `tools/render_og_image.py`. Per the rule in
`branding/README.md`, **delete the retired master** rather than
leaving it alongside the new one.
